## 为什么做

- 桌面 11 月已经按用户自己的 skill `ark-style-ui`（明日方舟式终端界面）重做了界面（桌面提交 `0b43962`），又改名 **Kirie 壁纸**、换了 K 字图标（`851e2b9`、`6d9a4d8`）。手机还是改版前那套：蓝灰、圆角、毛玻璃，名字"互动3D壁纸"，图标是线框立方体。
- **目标：手机和电脑看起来是同一个软件。** 外观、名字、图标都和桌面一致。

## 用户定的

- 界面用 `ark-style-ui`，和桌面看起来是同一个软件。
- 手机的软件名字、图标改成和桌面一样。
- 深色、浅色主题都做。
- 桌面后来加的功能（元素、天气、视频特效、唱片机、解锁动画、默认壁纸图库等）不跟。

## 目标

1. 三个页签（壁纸 / 视差 / 设置）、裁剪、提示条换成桌面的外观：直角面板加细框、中性灰配青色、色条加宋体标题、黑白反转按钮、警示斜纹。
2. 设置页加"界面主题"：夜间（默认）/ 日间 / 跟随系统，和桌面一样。
3. 手机桌面上显示 **Kirie 壁纸**，图标是桌面的 K 字图标。

## 不做

- 不改功能和流程：选图、裁剪、生成深度图、调参数、应用壁纸、设置页各项的行为都不变，JS 的逻辑只为换外观和主题做必要的改动。
- 不改包名 `com.wallpaper.live3d`（applicationId）：改了就成了另一个应用，已经装了的手机会丢掉设置和图片；桌面改名时也没动 appId（助手定的）。
- 不改 SharedPreferences 文件名 `wallpaper3d_config`、类名 `Wallpaper3DApp`、仓库文件夹名：用户看不到。
- 不改版本号，发布时再定。
- 不做 Android 13 的单色主题图标（monochrome），不补 API 24/25 的旧式 PNG 图标（现在就没有，见"已知"）。
- 不改壁纸服务里的页面（`assets/wallpaper/`）：它没有界面，只画壁纸。
- 不做多语言、平板 / 横屏布局。

## 反目标（做成这样就算失败）

- 和桌面并排看，配色、标题、按钮、标签明显不是一套。
- 有地方只在一种主题下看得清（写死的颜色），或者日间主题里状态栏图标是白的、看不见。
- 切换主题时页面重新加载：正在生成的深度图、选中但没应用的图丢了。
- 现有功能在新界面里找不到，或者按钮小得不好按。
- 出现明日方舟的名称、术语、Logo（skill 的规矩）。

## 约束

- 两个独立仓库，不建共享依赖。从桌面复制的文件，文件头注明来源和"改动要两边同步"（之前的约定）。
- 界面是 WebView 里的普通 HTML / CSS / JS，不引入框架和构建步骤。
- 桌面的 `ui/tokens.css` 用了 `color-mix()` 和 `:has()`，需要 Chromium 111 以上的 WebView。Android System WebView 跟着应用商店自动更新，小米也会推送；**要求 WebView 111+**，写进项目笔记（助手定的）。
- 浏览器开发预览（`.claude/launch.json` 的 `phone-dev`）要能看两套主题：假桥接加 `?theme=light|dark|system`。
- 真机验证由用户做；adb 连着时助手可以装上去看。

## 做法比较（助手定的）

| 做法 | 取舍 |
| --- | --- |
| **复制桌面 `ui/tokens.css` 和字体当底子（选这个）** | 色值、两套主题、按钮、分段、开关、滑块、状态标签和桌面一模一样，天然"同一个软件"。要做的只是放大触控尺寸、换主题选择器，再照桌面组件改 `app.css` 和 HTML |
| 照 skill 的 `references/` 重新推一遍 | 等于再做一次桌面做过的事，小地方（色值、字号、色条宽度）容易和桌面对不上 |

## 设计

### 1. 基础样式：`assets/ui/tokens.css`

- 用桌面 `ui/tokens.css` 替换现在的文件，文件头写明来源和"改动要两边同步"，并列出和桌面不同的地方：
  - **主题选择器**：桌面跟着 `prefers-color-scheme` 走（主进程设 `nativeTheme`）。手机 WebView 的 `prefers-color-scheme` 跟的是应用主题，不是用户在设置里选的，所以手机改成 `:root[data-theme="light"]` 选中日间，`data-theme` 由页面脚本按配置写在 `<html>` 上（见 §4）。日间的色值和桌面完全一样。
  - **触控尺寸**：按钮高 44px（`.sm` 36px），分段按钮每段高 36px，开关 48×28，滑块整体高 32px、竖条滑块 10×24。桌面是鼠标尺寸，手机按手指放大（现在手机的按钮就是 42 / 34px）。
  - **字体**：正文 `--font` 用手机系统字体（`system-ui, "Noto Sans CJK SC", sans-serif`，和现在一样）；去掉桌面里的微软雅黑、宋体（SimSun）这些 Windows 字体名。
  - 去掉手机用不到的：`kbd`、`.halftone`（手机这轮不用网点）。
- **字体文件**：复制桌面 `ui/fonts/`（思源宋体按字切成 101 片、Saira、两份 SIL OFL 许可证），约 6 MB，放到 `assets/ui/fonts/`。WebView 只加载页面上用到的字的那几片。APK 里已经有 100 MB 的模型，多 6 MB 影响不大（助手定的）。
- 删掉 `.glass`（毛玻璃），改用桌面的 `.float`（实底 + 细框 + 正下方一层阴影）。

### 2. 页面外观：`assets/app/app.css`、`app.html`

照桌面 `settings/settings.css` 的组件改，结构和 id 尽量不动（JS 靠 id 找节点）：

- **全局**：直角；正文 14px、行高 1.7、`font-variant-numeric: tabular-nums`；数字（滑块数值、分辨率、版本号）用 Saira（`--f-data`）；图标线头改成方头（tokens 里已有）。间距大体保持手机现在的密度：页面左右 16px、面板内边距 16px、分组之间 28px（桌面改版时也没按 skill 的网页尺寸放大）。
- **壁纸页顶栏 = 桌面标题栏**：左边 K 图标（22px，用 `assets/ui/icon.svg`，两套主题都用图标本来的颜色）+ **Kirie**（Saira 600）+ 竖线 + 小字"互动 3D 壁纸"（11px，`--text-2`）；右边还是状态标签。
- **视差、设置页的标题 = 桌面页面标题**：左边 8px 主色粗色条 + 宋体 900 大字 + 英文小字（`视差 Parallax`、`设置 System`）；视差页的"恢复推荐值"还在右边。
- **分组标题 = 桌面分组标题**：左边 4px 主色色条 + 黑体 700（画面、陀螺仪、界面、动态壁纸、后台运行、关于）。分组标题不配英文。
- **卡片、列表** → `.panel`（实底 + 1px 细框）；列表行之间细线分隔；设置页行首的图标方块改成直角。
- **预览**（壁纸页大预览、视差页小预览）：直角、1px `--line-strong` 细框，四角加桌面主视觉的 L 形细线（`.brk`），去掉圆角和阴影。预览上的浮层（顶部提示、"生成深度图后可以预览视差"）压在任意图片上，**固定用夜间颜色**（桌面做法）：深色底 + 左边 4px 主色条。
- **预览下面**：分辨率用 Saira；"使用中"是青色状态标签；原图 / 深度图是分段按钮（细框，选中项主色实底）。
- **深度图状态和进度**：状态标签式的一行（图标 + 文字，颜色不只靠颜色区分）；进度条换成桌面的分段进度条（4px → 8px 高、按 6px / 2px 切段）。
- **按钮**："选择图片""生成深度图"是普通按钮；**"应用壁纸"改成黑白反转按钮**（`.btn.contrast`，桌面的"应用壁纸"也是）；"恢复推荐值"ghost。一个区域只放一个强调按钮。
- **滑块**：桌面的竖条滑块，已走过的部分主色；对焦深度的深度滑块照桌面。
- **小米提示** → 桌面 `.desktop-notice` 的样子：左边一条 8px 警示斜纹 + 细框 + `--bg-2` 底，标题加粗，不用黄底。
- **关于**：第一行 K 图标 + **Kirie 壁纸** + 版本号（Saira），下面是设备。
- **底部页签栏**：保留（手机上比侧边栏好按）。`--ink` 底、顶上 1px 细线；选中项：底色亮一档（`--surface`）、顶边一条 4px 主色条、图标主色、文字 `--text` 加粗；没选中 `--text-2`。去掉现在的胶囊底。
- **提示条** → 桌面 `.toast`：`--surface` 实底、细框、左边 4px 色条（普通主色、成功绿、出错红，`border-image` 直角拼接）、一层正下方阴影；位置还是页签栏上方居中。
- **裁剪**：顶栏跟主题走（`--ink` 底），"确认"改成黑白反转按钮，"取消"ghost；中间放图片的区域保持黑底；裁剪框照桌面：1px 主色框、三分线、四角 L 形角点（3px，画在框里面），框外压暗用 `rgba(15,15,16,0.66)`；框和角点固定夜间青色（压在任意图片上）。底部说明改成 `.float`。
- **动效**：换页签时页面渐显 + 上移 8px（桌面 `fade-up`）；按钮按下沉 1px；`prefers-reduced-motion` 时都关掉（tokens 里已有，`app.css` 补上自己的）。
- `<title>` 改成 `Kirie 壁纸`。

### 4. 主题怎么生效（助手定的）

- **配置**：`ConfigManager` 加 `KEY_THEME = "theme"`，字符串 `dark | light | system`，默认 `dark`，其他值当 `dark`。不放进 `PARAM_KEYS`（那是数值参数），`getAll()` 里带上。壁纸服务的配置监听只认渲染参数和图片，存主题不会让壁纸重载（已核实 `LiveWallpaperService.prefListener`）。
- **桥接**：`AppBridge.setTheme(value)` 存配置并让原生层换颜色；`getPlatformInfo()` 加 `systemDark`（系统当前是不是深色）。
- **页面**：在 `<head>` 里、第一次画出来之前就按配置算出实际主题写到 `<html data-theme>`，不闪一下深色；"跟随系统"时用 `systemDark`。系统深浅变化时原生层调 `window.onSystemThemeChange(dark)`。浏览器假实现支持 `?theme=` 和 `?dark=0|1`。
- **原生层**：`MainActivity` 按实际主题设
  - 状态栏、导航栏图标深浅（`isAppearanceLightStatusBars / NavigationBars`）；
  - 根布局底色（系统栏后面露出的 `--ink`）和 WebView 底色（`--bg`）。
  - 清单里 `MainActivity` 的 `configChanges` 加 `uiMode`：系统切深浅时不重建 Activity（不重新加载页面），改走 `onConfigurationChanged` 通知页面。
- **打开应用那一瞬间的底色**：`res/values/colors.xml` 放日间色、`res/values-night/colors.xml` 放夜间色，窗口背景引用它们，系统画启动画面时按深浅挑。用户选了夜间或日间（不跟随系统）时，Android 12 起用 `UiModeManager.setApplicationNightMode` 告诉系统这个应用自己的深浅，启动画面也跟着；Android 12 以下启动那一下跟系统深浅，页面出来后就对了。
- 日间色值从 `tokens.css` 抄到 `colors.xml`，两边注释互相指一下。

### 5. 名字

- `strings.xml`：`app_name` = **Kirie 壁纸**（手机桌面、最近任务、系统动态壁纸列表里的名字都是它）；`wallpaper_description` = "互动 3D 视差动态壁纸"。删掉没人用的旧字符串（`btn_*`、`miui_hint`）。
- `MainActivity` 电池优化失败的提示"设置 → 应用 → 互动3D壁纸 → 电池"改成用 `app_name`。
- `app.html`：`<title>`、壁纸页顶栏（见 §2）。
- 文档：README 两份（标题、开头一句说明名字的意思、使用步骤里"选 Kirie 壁纸"；不写原名，和桌面一样）、`PROJECT_NOTES.md`。

### 6. 图标

- 自适应图标（`mipmap-anydpi-v26/ic_launcher.xml`，已有）：
  - 背景：纯色 `#0f0f10`（桌面图标底色）。
  - 前景：桌面 `assets/icon.svg` 的三个 K（深青 `#0d5a6e`、青 `#18d1ff`、白 `#ffffff`，往右下错开叠在一起），换算成 108dp 的 `vector` 路径，整体落在中间 66dp 的安全区里（各家桌面会裁成圆形或圆角方形，安全区外的会被裁掉）。所以 K 在手机上会比电脑上显得小一圈，这是系统规定。
- 应用内的 K 图标：复制桌面 `assets/icon.svg` 到 `assets/ui/icon.svg`。
- 系统动态壁纸列表的缩略图用的就是 `@mipmap/ic_launcher`，自动跟着换。
- `colors.xml` 里只给旧图标用的 `text_primary`、`text_secondary`、`primary` 删掉。
